# Chapter 15 — Interview Guide: Summary

## Key Takeaways
1. **Dart**: Null safety, event loop (microtask > event queue), isolates, sealed classes, records, patterns.
2. **Flutter**: Three trees (Widget, Element, RenderObject), BuildContext, lifecycle, Keys, Slivers.
3. **State**: setState (local), Provider/Riverpod/Bloc (app). Watch in build, read in callbacks.
4. **Architecture**: Clean Architecture, Repository pattern, Use Cases, DI, feature-first.
5. **Performance**: const, RepaintBoundary, ListView.builder, Impeller, Isolate.run.
6. **System Design**: Requirements → Architecture → Data Model → Deep Dive → Performance → Testing.
7. **Behavioral**: STAR format. Prepare: challenging bug, trade-off decision, team disagreement.
8. **Live Coding**: Clarify → Think aloud → Data model first → Structure then details → Edge cases.
