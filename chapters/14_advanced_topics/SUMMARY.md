# Chapter 14 — Advanced Topics: Summary

## Key Takeaways
1. **Flutter Web**: html renderer for SEO, CanvasKit for quality. GoRouter handles URLs.
2. **Flutter Desktop**: window_manager for sizing, PlatformMenuBar for menus, Shortcuts for keyboard.
3. **Flame**: Component-based game engine. SpriteComponent, collision detection, game loop.
4. **AI/ML**: TFLite for on-device inference, ML Kit for text/face/barcode, Gemini API for LLMs.
5. **Impeller**: Default engine — pre-compiled shaders, multi-threaded, no jank.
6. **Shaders**: GLSL fragment shaders loaded via FragmentProgram, painted on GPU.
7. **FFI**: Call C/C++/Rust directly — near-native speed, no channel overhead.
8. **WASM**: `flutter build web --wasm` for faster web execution.
9. **Dart 3.x**: Sealed classes, records, patterns, extension types, macros (experimental).
